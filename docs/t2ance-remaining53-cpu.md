# t2ance 未复验 53 题：独立 CPU 批次

冻结来源仍为原 LiveCodeBench v6 175 题和 `t2ance/code-solutions` 的 60 个机械候选；此前固定七题已经独立通过 297 个测试，不重复计入本次分母。其余 53 题按原种子、题目 ID 哈希排序后分成四个互斥批次，数量为 14/13/13/13。选择不读取代码运行结果、DAG 或 PALS 分数。

`package_t2ance_remaining53.py` 仅复制冻结来源、必要代码和 Slurm 脚本，并用清单白名单生成 USTAR 包，不执行候选程序。B1 上只在 PALS 项目内解包；数组任务 0 先作门槛，结果及隔离控制均合格后再提交任务 1–3。每个任务在独立 CPU Slurm 分配内核对原题与源哈希、解码原始测试，再由 Linux seccomp 子进程逐例执行。不同批次输出至独立子目录，失败和超时均保留，不补采样。

完成后 `audit_t2ance_full_execution.py` 对四个批次分别从原题和冻结来源重建输入、验证代码快照、全部原始测试和结果；与七题旧审计合并时按 item ID 去重并要求 60 题恰好覆盖。CPU 通过仅说明该参考程序在本项目冻结测试上的执行结果，**不**自动证明 DAG 的逻辑依赖或正式 PALS 数据质量。
