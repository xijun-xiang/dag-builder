# 正式运行工程修复（不修改科学定义）

原冻结代码 `cc94c39` 的审查发现：InternLM3 需要本地自定义实现，但后端拒绝加载；SIGTERM/SIGKILL 后独占文件锁阻止续跑，总启动器也不支持已有运行目录。

本版不修改图算子、题目筛选、固定位置、模板、生成温度、repeats、g/N/D 或统计分析。

1. 默认禁止自定义代码不变。模型级 allowlist 固定 revision 和全部 `.py` 哈希，拒绝额外源码、软链接和跨仓库 auto_map；实际环境通过 `runtime_versions` 检查。只加载本地 safetensors。
2. 内核生命周期锁替代独占文件锁，不删除锁 inode；强杀后可重新取得锁。真实输出文件系统有单独互斥探针。
3. 初始化原子发布；续跑重新核验输入、配置、代码和分片数，已完成结果校验哈希；已落盘 E2 generation 不重采样。
4. 模型级启动器、canary、全量实验共用同一生命周期逻辑。恢复必须显式 `--resume`，每次尝试使用新日志/分析目录。异常只终止本启动器创建的子进程，不提交其他任务。
5. 逐模型真实 canary 仍是必要条件：原生 masked loss 数值对照、八分片执行、生成格式及最终逐 token 算术检查。工程测试通过不等于已完成真实模型验收。

离线回归覆盖 SIGTERM/SIGKILL、并发锁、生成后评分失败、续跑禁止重采样、已完成结果损坏、输入/config/分片变更、初始化中断、自定义代码变更与外部 auto_map。测试均为合成数据，不是科学效果证据。
