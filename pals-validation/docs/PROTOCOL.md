# 冻结协议 gpqa-validation-v1

## 1. 数学口径

对目标步骤 token 序列 y=(y₁,…,yL)，完整前缀 C、删除指定步骤后的 C⁻：

`g = (1/L) Σ [log p(y_j | C,y_<j) − log p(y_j | C⁻,y_<j)]`

`v=max(−g,0)`。E1 的 `M=mean_steps(v)`、`G=mean_steps(g)`；步骤等权，不按长度再次加权。

E2 在同题、同前缀、同温度生成 R 次，`N=mean_r(v_r)`，`D=sample_std_r(g_r)`，分母 R−1。D 是标准差，不是方差。NLL 仅为诊断对照，不混入 N 或 D。评分使用原始 logits，即评分温度恒为 1，不使用生成温度缩放。

## 2. 输入

GPQA 题目与四个选项始终提供。输入节点数组必须已经是合法拓扑序；拒绝环、重复 ID、非法父节点和静默排序。accepted candidate fallback 需带指定审核诊断。模型审核通过不等于人工 gold，语义错误仍需独立审查。答案节点不参与被评分步骤与 E2 目标选择。

## 3. E1

原轨迹破坏：固定首节点，枚举后续相邻且存在直接依赖的两个步骤；确定性哈希选一个并交换。其他文字和相对顺序不动。

拆树：被多个后继使用的共享节点及其祖先固定在前缀；剩余部分按依赖形成向结论汇合的树。按原顺序确定兄弟子树顺序，完整输出子树，不复制共享节点。合法算子只交换同组两个非平凡完整子树（每棵至少两个节点），不打乱子树内部；换后再次检查全部边，不只检查最终节点。多个候选组按固定哈希选一个。具体代码为 graph.py 的 forest 实现。

破坏对照在同一个 forest baseline 上选相邻依赖对交换。合法与破坏的主对照使用同时适用的同题、三版本均可评分的相同目标节点集合。不同版本的首节点可能不同，所以不能直接把各自全轨迹均值相减当成严格配对。另行保留各版本原生轨迹描述统计。

每个可评分目标删除线性前缀中紧邻的前一步；重排后该删除对象可能改变，这是 LOCAL 定义，不是固定父节点因果效应。可选 parent probe 固定目标，用父节点与非祖先对照分别删除，匹配位置距离≤2、按空白分词的长度比≤2。

合法排序不保证语言连贯性或 g 完全不变。本实现没有把“CI 覆盖 0”解释为等效；若要正式声明等效，应另外预定等效界值与检验。

## 4. E2 固定的位置

每题候选是所有有父节点的非答案步骤。选择使以下哈希最小的节点：

`sha256(json.dumps([20260915, 'target', item_id, node_id], ensure_ascii=False).encode())`

固定前缀仅包含该目标的全部祖先，按节点 ID 打破拓扑排序平局；不包含无关的原轨迹步骤。前缀最后一步保证为该目标的一个直接父节点。模型看到题目、选项、祖先步骤，以及下一步开始标记；**不看到选中的 gold 目标文本**。续写内容未必语义上等于 gold 节点，不把它解释成强制命中了中间节点。

每档生成温度 0.3 / 0.7 / 1.2，8 repeats，top_p=1、top_k=0、重复惩罚=1。只采样一个步骤，到首个闭合标签停止。评分删去固定前缀最后一步，两个条件下评分同一个生成步骤。无效、截断与空步骤保留，不补采样至凑满。已知题面异常题 9220d9a8a6f7295fa73b 从 E2 排除，详见预处理 selection。

## 5. Token 与运行约定

使用模型自身 chat template；目标 body 与上下文分别 tokenize，再拼接 token ID。这一显式边界保证完整／删除条件的目标 ID 完全一致，但不宣称等同于把完整字符串一次 tokenize。g 只评分 body，不包含 step 标签。teacher forcing 的 logits 从 context_length−1 起对齐目标，保存每个目标 token 的两侧 logprob。

上下文溢出报错，不裁剪。生成预算默认 2048 个新 token，是单步预算，非整段 CoT 预算。每行独立检测结束标签，保留原始 token 与解析边界。seed 按 run 的 job identity 派生，每个温度不同；只承诺固定环境重现，不承诺跨 GPU/库版本逐位一致。

## 6. 统计

题目是重采样单位，bootstrap 5000 次、固定 seed，给出均值及百分位 95% CI。E1 三版本比较使用共同目标，E2 主分析使用所有温度完整 repeats 的共同题集。输出不适用与失败数量。

当前统计是单模型、单数据集分析；多个模型的总体结论与多重检验校正需另行规定，不把每个 repeat 当成独立题目。所有温度表现不预设单调，均需报告。
