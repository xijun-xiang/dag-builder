# E3 全分母续跑 v1

2026-10-09 用户明确批准：全量尝试、跑多少算多少，保留无效，不因模型格式覆盖率低停止。
这是**执行与接纳政策的显式修订**，不是原低覆盖失败批次被追认为通过。

## 科学合同

- Llama-3 和 InternLM3 仍分别覆盖同一 15,898 题；原三模型不重跑。
- 提示、Tgen=0/Tscore=1、原 v2 解析、g/AS=G/NS=M、输入、模型、固定批次成员和种子均不变。
- Llama 沿用原生 8192 容量 cap；不截题、不改 RoPE、不加重复惩罚或提早截断长输出。
- 原始完整 raw 与分数逐文件校验后导入。原 48/40 条不重生成、不改写原目录。
- Llama 64 条已尝试但缺 raw 的旧记录全部基础设施 N/A，禁止重新生成；15,786 未尝试题继续。
  InternLM 保留原 40 条，继续 15,858 未尝试题。最终各 15,898 分母不变。
- 暂不启用 v3 冗余标签候选或自然语言编号分段；避免在选择性缺失之上再引入未冻结评分范围。
- 旧覆盖率阈值仍计算和保存，但是 report-only；格式失败、单步、截断、触顶、不利结果均保留。
  数值、模型身份、数据完整性、代码隔离及运行故障仍 fail-closed，不自动修复或重试。
- AS/NS 的均值和题级区间只代表可评分输出；必须同时报告全题量、无效分母和来源。

## GPU 调度

8 个持久 worker 首先各自完成真实 native masked-loss 与重复评分校验。
父进程重算并确认全部数值门槛后，放行共享固定批次队列。领取在短文件锁内原子记账，
不重新分配已领取批次；任意 worker 异常时整项失败并保留证据。
每个空闲 worker 领取下一批，不等待首五批覆盖率；首 40 题仍按原题集留存覆盖率报告。
全量完整性审计逐个核对领取、完成、原始输出及 8 worker 收据。

停止检测只复制末 64 token（CPU 逐 token 等价已测试）；每 30 秒有解码进度事件，
每题达到原停止条件即落盘，批次返回逐项验证相等。固定批次内仍有长尾，
不承诺每时每刻满卡或未经测量的提速倍数。forward 卡住仍需外部监控，不能靠心跳自称正常。

## 部署与验收

只在新 run 中执行 `greedy_cli init --continue-full-from OLD_EXPERIMENT`；
限单扩展模型，配置、输入、source manifest/attempt/raw/receipt/score 均哈希绑定。
旧运行须先确认终态且无并发写入。CPU init 重新验证模型、兼容架构、全题上下文、安全隔离和导入。
GPU真实数值门槛嵌入正式任务，不新增丢弃式GPU canary。
沿用一次性 HOLD-submit/资源路径依赖验收/release，GPU→受限CPU判分审计。
每站至多8GPU，A1/B1独立；旧失败和取消记录不可篡改。

只有来源中已明确固定的中断项可成为基础设施 N/A；新运行若出现不确定 generation，仍停止。
这不授予任意缺失文件变 N/A、无限续跑或静默重试的权限。
