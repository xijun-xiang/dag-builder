# B1 真实模型发布前检查

目的：验证工程实现，不检验 PALS 效果，不以两题推断全量成功率。

## 固定设置

- 模型：既有本地 Qwen2.5-7B-Instruct 快照，初始化保存逐文件 SHA256，无模型下载。
- 输入：118 题导出中同时适用于 forest 合法／破坏配对和 E2 的题，按 item ID 排序取前两题；选择不看评分。
- E1：两题全部适用版本，共 55 个目标评分任务。
- E2：两题 × 温度 0.3/0.7/1.2 × 8 repeats，共 48 个生成步骤；评分温度恒为 1，单步预算 2048 tokens。
- 环境：NVIDIA H800，PyTorch 2.11.0+cu130，Transformers 5.6.0，BF16，SDPA；8 个单卡分片，不是 tensor parallel。
- Slurm：110381，defq/evaluation，tko-b1-nv-dgx51，8 GPU，32 CPU，256 GiB 内存请求，20 分钟上限。
- 调度终态：COMPLETED，退出码 0:0，实际运行 2 分 44 秒；GPU 已释放。
- 容器：既有只读 `lmsysorg+sglang+v0.5.12+infix+v6.sqsh`，不依赖容器中的 infi-evalscope。
