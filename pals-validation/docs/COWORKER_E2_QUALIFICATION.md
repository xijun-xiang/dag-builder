# GSM8K / MMLU E2 的 score-blind 合格子集

此版只筛选整条原始记录，不改题干、选项、步骤、边、答案或 `e2_anchor` 的哈希选择。输入为原 1,539 条 model-accepted DAG 的 `audit-v4`；所有筛选发生在查看 PALS 分数之前。`human_approved` 仍为 false。

运行 `scripts/qualify_coworker_e2.py --audit-dir AUDIT --psych-review REVIEW --output NEW_PRIVATE_DIRECTORY`。程序核对审计文件的 SHA、1,539 条完整分母和 E2 候选集合；输出 1,539 行逐题流转、E2 专属排除决策和摘要 manifest。`REVIEW` 是私有的逐题盲审文件，不包含在 Git。输出目录只能新建，默认 0700；文件 0600。`e2_decisions.json` 中的 `e1` 字段是空占位，合并 E1 决策时必须保留实际 E1 排除表，不能以这个空表覆盖。

## 主子集规则

1. 沿用已有 `e2_anchor`，不重选目标：删去节点必须是解答中的 `derived`/`knowledge`，而不是题面、选项或 `given`。题面和选项在两个评分条件下始终可见，不能把原本显示在那里的前提称为“已删去”。
2. 锚点指向解答中的 `derived` 中间步骤，并且它必须被至少一个**非答案步骤**直接使用。这样主子集明确检验过程中的续写位置，而非只在终端选项/答案处试探。这个限制是更窄的验证协议，不是宣称被排除的终端步骤都错误。
3. 排除显式选项结论、长选项的高词项重叠及与父步骤/题干的字面重复；同一包内题干+选项归一化后完全重复者只计一个独立题。词项规则只识别明显近重复，不能充当语义裁判。
4. 心理／社会剩余 44 题另外逐题作 assistant score-blind 检查：27 保留、11 语义不确定、6 硬排除。不确定者不纳入主子集；逐题 ID 和理由在私有 review 文件。此审查不是人工 gold 标注。

## 不看 PALS 分数的抽样核查

GSM8K 与 MMLU 数学各按固定哈希选前 12 题检查题干、被删前提、锚点目标与局部边；样本中未发现明显反例。示例：GSM8K `test:833` 从 Saskay 的 12 英寸推 Kagiyami 的 48 英寸；数学 `elementary_mathematics:test:5` 先得括号内 `8÷4=2`，再计算中间括号和。样本检查不能证明其余题全部语义正确。

心理／社会对筛后全部 44 题检查，而非抽样。明确坏例：`human_sexuality:test:32` 的题干在“No sex”处截断；`high_school_psychology:test:118` 仅从定义直接复述选项；`sociology:test:199` 父步骤已经逐字包含待选答案。还有一些题的目标几乎只是父步骤的改写，列为不确定，不进入主子集。保留例包括 `professional_psychology:test:442` 的 z-score 中间计算与 `high_school_psychology:test:145` 的中位数计算。

## 结论边界

该子集可以用于**明确限定为 model-accepted 合成 DAG、固定中间锚点**的 E2 实验。它不能代表全部 1,539 题，更不能冒充人工 gold。生成任务只固定祖先前缀，让模型自由续写下一步；参考目标用于选位置，不会被强制生成，故结果是“该前缀上的条件支持波动”，不能说模型重复生成的是同一个语义步骤。正式分析还必须分别报告三包分母、各温度计划/有效/完整题数、失败与置信区间；不能只报告留下来的漂亮均值。
