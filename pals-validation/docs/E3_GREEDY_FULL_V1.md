# E3 正式原生轨迹协议：贪心生成、MMLU 全 57 子集

用户于 2026-10-06 批准本地/CPU 验收后直接提交正式全量 GPU 作业。
不再单独排 GPU canary；真实数值门槛和首批检查在正式 allocation 内完成。

## 固定范围

Qwen2.5-7B-Instruct、Phi-4-mini-instruct、Qwen3-14B，各自生成并评分自身轨迹。
GPQA 198、GSM8K 1319、HumanEval 164、LCB v6 新增 175、MMLU 14042。
每模型 15898 题，共 47694 次计划生成。MMLU 从官方 57 个 `test` 分片读取，
revision 为 `c30699e8356da336a370243923dbaf21066bb9fe`，不使用 DAG 接受子集。
不按问题内容去重；按官方 subject/test/row 保留来源身份。选项重复的题保留过程，正确率 N/A。

## 方法

- `do_sample=false, num_beams=1`，元数据 T=0；不将零温度传给采样器。
- score T=1，沿用 E1/E2 显式上下文/目标 token 边界、相同目标 token、相邻前一步删除。
- 每题一次，batch=8，8 个固定 shard，Qwen3 `enable_thinking=false`。
- 输出预算知识/数学 8192 token，代码 16384；检查 prompt+budget 不超过模型上下文，不静默截断输入。
- G=题内目标步骤 g 的均值；M=题内 max(-g,0) 的均值；AS=G，NS=M。
- 题目等权，不按 token/步骤数量给长轨迹加权。一步题 N/A，两步可定义一个 g。
- W 仅作为旧内核兼容字段存在，不作为新实验指标。无额外共同评分者，无跨重复 D。
- 辅助 NLL 仅覆盖与 g 相同的目标步骤，不称为整条输出 NLL。

## 粒度与解析

新提示词要求一个主要推导动作及其中间结论对应一个步骤，不强制最少三步。
优先沿用已验证的过程/答案解耦解析。步骤结束标签缺失时，只在下一个显式
`<step>` / `<answer>` 边界确定原文片段；识别已知 `</step` 残缺结束符，
不按句号硬拆、不使用 LLM judge、不改写或补造推理。原文 span 和采用的规则均保存。
步骤边界歧义或推理中途截断记无效。若明确进入 `<answer>` 后才截断，完整推理
可以评分，答案不可提取。标签恢复不代表语义粒度已获认证；正式结果必须报告步骤数、
步骤长度、两步/3–5步/6步以上分层和共同有效题集；不依 g 或正确率筛选数据。

## 生命周期与资源

1. 本地 CPU：旧/新单测、真实旧轨迹解析和算术重放、全部来源数量/哈希。
2. 集群无 GPU CPU init：隔离判分合成自检、模型文件哈希、全部题目的真实 tokenizer
   与上下文预算检查、输入及协议冻结。保存 init 的作业 ID、协议 ID 和证据哈希。
3. 每模型一个正式 8-GPU 长作业：模型每 shard 加载一次，真实 masked-loss
   数值门槛后，完成首批五基准各8题，随后在同一 allocation 连续生成和评分全量。
   每批 raw、receipt 和每题 scores 原子落盘；首批是正式数据，不丢弃、不重生成。
4. 每模型无 GPU CPU 作业：安全答案判分、逐 token/原文/协议/分母审计。
5. 下一个模型依赖前一模型 CPU 审计成功；全程最多8 GPU。CPU/GPU 作业都不自动重排。

GPU 作业上限24小时，CPU判分审计4小时；结束前1小时不开始下一批，保留完整断点并停下报告。
这不是24小时完成保证。若最后一个在途批次被硬超时中断，无完整raw则标为不确定生成，
不能自动重新生成。相同批次raw完整且已封存，可继续确定性评分，不增加生成次数。

真实数值门槛：重复 logprob 最大差 <=1e-5；两侧原生 masked-loss 误差 <=0.005。
格式复核沿用旧工程阈值：首批总体结构有效率 >=90%，各基准 >=75%。随后每 shard
同基准最近32题结构有效率低于75%停止新增生成并报告；M=0、答错或正常一步题不触发。
这些是工程停止阈值，不是按结果筛题的规则，所有失败/N/A保留。
全量 CPU 审计再次报告覆盖率，低于总体90%/各基准75%时阻止后续模型自动启动，留待用户决策。
